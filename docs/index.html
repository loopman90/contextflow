Installation

Get started in minutes

  1. Download main.js, manifest.json and styles.css from the latest release.
  2. Copy them to .obsidian/plugins/contextflow/ in your vault.
  3. Enable ContextFlow in Settings → Community plugins.
  4. Open a Markdown note and run Open Quick Insert.

See the complete installation guide for development setup and troubleshooting.

Privacy

Your notes stay local

ContextFlow stores settings and small action metadata through Obsidian's plugin data API. It does not upload note content, selections, clipboard data or form values.
